⚡ Lightning Strike Prediction Dashboard

AI-Powered Real-Time Lightning Risk Monitoring

💡 Idea & Novelty

LPM integrates K-Means spatial clustering with a CNN severity predictor and real-time visualization. It provides interpretable geospatial zones (Red/Orange/Yellow), continuous updates from meteorological features, and an interactive map UI.

  • ⚙️ Hybrid ML: clustering + supervised CNN for accuracy and interpretability.
  • 🌍 Geospatial risk zoning using latitude & longitude clustering.
  • 📡 Interactive dashboard with heatmap, clusters, and alerts; ready to connect to Flask endpoints.
