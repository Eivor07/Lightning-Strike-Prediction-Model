# Lightning-Strike-Prediction-Model
A machine learning-based system that predicts lightning occurrences using meteorological parameters like temperature, humidity, and pressure. The model analyzes weather data to provide early warnings and reduce the risk of lightning-related disasters.

## Project Structure
- `data/`: Contains the lightning strike datasets.
- `docs/`: Research papers, project reports, and presentations.
- `src/`: Source code for the project.
    - `ml/`: Machine learning training pipeline and models.
    - `frontend-legacy/`: Original HTML/JS dashboard focus on India.
    - `web-app/`: Advanced Next.js dashboard focus on New Zealand.
- `tests/`: Accuracy test results and performance benchmarks.
